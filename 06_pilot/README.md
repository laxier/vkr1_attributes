# 06. Пилот и пороги

Пилот на первых 100 карточках: проверить, что протокол этапа 05 работает на всех 8 моделях, и до основного прогона записать пороги для гипотез. Гипотезы пилот не подтверждает.

## Что здесь лежит

- `results/` — 32 файла `pilot__<модель>__<режим>__<формат>.jsonl` (ответы по карточкам), `summary.csv` (сводка запусков), `bootstrap_pilot.md` (интервалы и разности), `bootstrap_log.txt` (журнал запусков `bootstrap.py`).
- `thresholds.md` — пороги T1, T2 и допуски H3, H4.
- Отчёт этапа (`*.docx`) лежит рядом и в `.gitignore`.

## Что запускали

8 моделей × 4 запуска (zero-shot / few-shot, свободно / по схеме) × 100 карточек. Условия из протокола: 4 бита (nf4), жадная генерация, одна инструкция, 5 примеров few-shot. Запуски на A100 40 ГБ в Colab, около 7,0 часа генерации (≈38 единиц Colab). GigaChat — на transformers 4.57.6 (только там квантуются её эксперты, см. `05_protocol/README.md`), остальные на 5.19–5.20.

Ноутбук: `../05_protocol/05_run_model.ipynb` с `SPLITS = ["pilot"]`, для GigaChat — `../05_protocol/05_run_model_gigachat.ipynb`.

- Лучшие результаты (Gemma 4 E4B, Ministral 3, YandexGPT-5 Lite) на 100 карточках статистически не различить.

## Входные токены

На пилоте в `summary.csv` записаны только выходные токены (`токенов_среднее`). Длину промпта в токенах можно восстановить без повторного прогона: `prompt_tokens_cell.py` (вставить ячейкой в ноутбук после ячеек с данными и промптом, нужны только токенизаторы, без GPU). Результат `prompt_tokens_pilot.csv` положить в `results/`. Для основного прогона ноутбук уже пишет `токенов_вход_среднее` в `summary.csv`.

## Пороги

| обозначение | значение | где применяется |
|---|---|---|
| T1 | micro-F1 не ниже 0,90 | H1, ОГ |
| T2 | ложные на `null` не выше 0,10 | H1, ОГ |
| допуск H3 | потеря F1 со схемой не больше 0,02 | H3 |
| допуск H4 | разрыв heldout − val не больше 0,05 | H4 |

Как выбраны и как применяются — в `thresholds.md`.

## Особенность данных

У 20 из 100 карточек разрешение названо без цифр (Full HD, QHD, 4K), эталон `null`, а модели отвечают цифрами. Это поднимает долю ложных на `null`. Эталон и промпт не меняем, рядом считаем вторую метрику «без этих пар» (см. отчёт этапа).

## Как воспроизвести

Из папки `05_protocol`:

```bash
python bootstrap.py pilot all    # H2 и H3 для всех моделей
python bootstrap.py pilot md     # все таблицы в 06_pilot/results/bootstrap_pilot.md
python bootstrap.py pilot gemma4_e4b/few-shot/schema qwen35_9b/few-shot/schema   # разность двух запусков
```

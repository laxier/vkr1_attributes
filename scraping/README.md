# scraping: сбор карточек мониторов DNS

Сбор идёт из обычного браузера на открытых страницах DNS, без входа в аккаунт. Только товары в наличии.

| Файл | Что это |
|---|---|
| `dns_saver.user.js` | юзерскрипт Tampermonkey: собирает ссылки с выдачи и сохраняет открытые карточки (описание + характеристики) |
| `dns_scroll.js` | скрипт для консоли: прокручивает выдачу до конца, чтобы список ссылок подгрузился целиком |
| `prompt.txt` | промпт, по которому ИИ написал `dns_saver.user.js` |
| `ЛР-1 ПЗМО Тимофеев К Ю ПМ23-5 - Отчёт Сбор данных DNS.docx` | отчёт: источник, метод, ограничения, код и промпт в приложениях |

## Как запускать

1. Установить Tampermonkey и добавить `dns_saver.user.js`.
2. Открыть категорию «Мониторы» на dns-shop.ru, включить фильтр «в наличии».
3. Вставить `dns_scroll.js` в консоль (DevTools → Console), дождаться конца списка. Ссылки сохраняет юзерскрипт.
4. Нажать «▶ Авто» на панели: скрипт откроет случайные карточки с паузой 2–4 секунды и сохранит их.
5. Кнопка «JSON» скачает `dns_cards_<N>.json`. Положить файл в `data/` (папка в `.gitignore`).

Скрипты написаны с помощью ИИ (Claude), запускались и проверялись автором. Тексты описаний в репозиторий не попадают.

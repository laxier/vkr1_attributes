# ВКР: реализация модели извлечения структурированных атрибутов товаров из их текстовых описаний.
Автор: Тимофеев К Ю, ПМ23-5. Дисциплина: «Прикладные задачи машинного обучения».

## Идея

Из русскоязычного описания товара нужно получить JSON «атрибут → значение» по схеме категории.
Сравниваются 7–8 универсальных LLM (zero-shot, few-shot, при возможности LoRA/QLoRA) по единому протоколу.
Данные: синтетика (генерирует LLM) для примеров и обучения, реальные карточки (скрапинг) для проверки.
Реальные данные делятся на **real-val** (выбор модели, промпта, генератора) и **real-test** (один финальный прогон).

## Структура

```
notebooks/        ноутбуки по этапам
docs/             текстовые материалы (обзор литературы)
outputs/          артефакты запусков (outputs/literature коммитится)
data/             данные (не коммитится)
```

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate #
pip install -r requirements.txt
jupyter notebook          # запускать из корня репозитория
```

Ноутбук 1 по умолчанию работает без интернета (`RUN_ONLINE = False`). Чтобы воспроизвести поиск в arXiv и проверить ссылки, поставьте `RUN_ONLINE = True`.

## Правила эксперимента

- Решения (модель, промпт, learning rate) принимаются только по real-val.
- real-test открывается один раз.
- Пороги гипотез фиксируются до основных прогонов.
- Скрапленные тексты в репозиторий не добавляются (только идентификаторы и ссылки).

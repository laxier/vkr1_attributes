# 04. Синтетика: генерация описаний через Claude

`generate.py` просит Claude написать описание монитора с заданными характеристиками. Эталон известен по построению. После генерации текст проверяется теми же правилами, что и реальные карточки в `03_eda`: значение из эталона названо в тексте (и только оно), для `null` атрибут не назван. Не прошедшие проверку описания отбрасываются.

Из реальных данных берётся только пилот (100 карточек): сколько раз упоминается каждый атрибут, какие бывают значения, 3 случайных текста как образец стиля. Val и test не читаются. Описание отбрасывается, если делит с образцом 6 слов подряд.

## Наборы

| имя | сколько | зачем |
|---|---|---|
| `fewshot` | 20 | примеры для few-shot в промпте |
| `heldout` | 80 | синтетический контроль, чтобы измерить разрыв «синтетика → реальные» |
| `train` | 1000–3000 | обучение LoRA / QLoRA (позже) |
| `train_names` | 500 | добавка к train для LoRA: разрешение названо словом (Full HD, QHD, 4K), в половине без цифр (эталон `null`), в половине с цифрами |

У каждого набора свой seed, чтобы не пересекались.

## Запуск

Ключ лежит в `.env` в корне репозитория (файл в `.gitignore`):

```
ANTHROPIC_API_KEY=sk-ant-...
```

```bash
pip install -r ../requirements.txt
cd 04_synthetic
python generate.py fewshot 20 1
python generate.py heldout 80 2
python generate.py train 2000 3
python generate.py train_names 500 4   # отдельный файл, train.jsonl не трогается
```

Зачем `train_names`: на пилоте (этап 06) у 20 из 100 карточек разрешение названо только словом, эталон `null`, а модели отвечают цифрами; в `train` таких карточек нет. Решение принято по пилоту, до просмотра real-val. Оценка по логу train: около 550 запросов, около 0,7 млн входных и 0,22 млн выходных токенов.

Результат в `data/synthetic/<имя>.jsonl` (папка `data/` в `.gitignore`). Скрипт можно прервать и запустить снова: он продолжит с того места, где остановился.

## Что известно заранее

- Значения атрибутов берутся независимо (например, разрешение и диагональ не согласованы между собой). Для извлечения это не важно, но при желании можно брать значения совместно из одной карточки пилота.
- Правила проверки скопированы из `03_eda.ipynb`. Если меняешь правила эталона там, меняй и здесь.
- Claude только генерирует синтетику и в сравнении моделей не участвует (условия эксперимента).
